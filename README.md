
# 🧮 Calculator Application

A simple and user-friendly calculator application developed using Flutter and Dart.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Remainder (%)
- Decimal number support
- Clear All (AC)
- Delete (DEL)
- Division by zero handling

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design 3
- StatefulWidget
- setState()
- GridView.builder

## 💻 Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/suraj-pandey07/calculator-app-flutter.git
```

**2. Open the project in VS Code**

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
